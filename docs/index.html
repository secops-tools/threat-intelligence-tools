Included CLI utilities

Every script in scripts/ runs on Python 3.9+ with standard library modules only.

check-ip.py

Query IP reputation across Shodan InternetDB, GreyNoise, AlienVault OTX, AbuseIPDB, and VirusTotal.

python3 scripts/check-ip.py 1.1.1.1

check-feeds.py

Measure feed HTTP status, latency, Last-Modified headers, and payload structure.

python3 scripts/check-feeds.py

check-logs.py

Scan Nginx, Apache, or Linux auth logs against public or local IP blocklists.

python3 scripts/check-logs.py /var/log/nginx/access.log

convert-feed.py

Convert indicator lists between JSON, CSV, plain text, and STIX 2.1 bundles.

python3 scripts/convert-feed.py iocs.txt out.json --to stix

dedupe-iocs.py

Refang, classify, and deduplicate mixed IPs, domains, URLs, and file hashes.

python3 scripts/dedupe-iocs.py raw.txt -o clean.txt

cve-monitor.py

Check CISA KEV and NIST NVD 2.0 for recent CVEs matching your software stack.

python3 scripts/cve-monitor.py nginx openssh --days 30
